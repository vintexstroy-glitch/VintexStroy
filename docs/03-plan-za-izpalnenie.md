## Защо този ред

Ядрото (Врата + Журнал) е **носител-агностично** — пише се СЕГА, без да чакаме
решението за носител. Всичко останало виси на него. Залогът се изплати: носителят
беше избран после (В), без нито един ред от ядрото да се пренапише — и портовете
с по две реализации го доказват, вместо да го обещават.

```
П1 ЯДРО ──┬── П2 СМЯТАЧ ──┬── П4 ИЗГЛЕДИ ── П6 ГАНТ
          │                │

          │
          └── П5 НОСИТЕЛ ── П7 МОСТ
```

## П5 · НОСИТЕЛЯТ · решението

**Зависи от:** П1 (само от договора). **Отключва:** П7.

✅ **РЕШЕН — В · местно-първо** (ADR-001; доказан с мерки, `docs/09` §4б). Числото отпадна
като спирачка: при sync-engine-подобен местен носител прагът е далеч над всичко,
което този бизнес прави. Мерките го показват с огромен запас — всичките пет
бюджета в зелено (`docs/09` §4б).

**Б · свой сървър** се връща при голям клиент — като
НОСИТЕЛ, не като втори двигател. Портовете имат по две реализации; трета е
добавка, не пренаписване.

Остава от тази партида: **проверка на веригата по разписание** (днес е бутон +
автоматична проверка на котвата при тръгване).
