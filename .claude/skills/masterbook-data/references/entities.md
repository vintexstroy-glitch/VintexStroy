# Същности · MasterBook

Всяка същност е ПРОЕКЦИЯ върху Журнала (event-sourcing). „Ключът" идентифицира същността през
всичките ѝ събития; „състоянието" е агрегат на събитията, не един ред.

---

## Имот (М01)
- **Определение:** място/сграда в портфейла — неговият **Имот** (И131: „едната суровина е Имот(Място)"); в Журнала днес е `МястоЗаписано`, в делата — `myasto`.
- **Ключ:** `имот_id`
- **Връзки:** има много **обекти** (единици); има Имот без Обект, няма Обект без Имот (ADR-155 · резен 99 за пазача). Принадлежи на **портфейл/собственик**.
- **Ключови полета:** адрес, тип (жилищен/офис/парцел), площ, статус (актив/продаден/в строеж).

## Обект · единица (М01)
- **Определение:** отделно даваема/продаваема част (апартамент, гараж, паркомясто, офис) — неговият **Обект**; в Журнала днес е събитието `ИмотДобавен` (адрес · единица), защото събитията не се преименуват (правило 1 · ADR-155).
- **Ключ:** `единица_id` (дете на `имот_id`)
- **Връзки:** 0..1 активен **договор** за наем; 0..1 **продажба**.
- **Ключови полета:** етаж, площ, наемна цена (центове), състояние (свободна/заета/продадена).

## Наемател (М02)
- **Определение:** страна, която плаща наем по договор.
- **Ключ:** `наемател_id` (той е и **контакт**)
- **Връзки:** има много **договори**; поражда **вземания**.

## Договор (М02)
- **Определение:** наемно правоотношение върху единица.
- **Ключ:** `договор_id`
- **Ключови полета:** единица_id, наемател_id, начало, край, наем (центове), индексация, депозит.
- **Състояние:** активен, ако `начало ≤ днес ≤ край` (или край празен).

## Продажба / Сделка (М03)
- **Ключ:** `сделка_id` · единица_id, купувач(контакт), цена (центове), капаро, нотариус, дата на прехвърляне.

## Кредит (М04)
- **Ключ:** `кредит_id` · обезпечение (имот_id), главница, лихва, погасителен план (вноски).

## Счетоводен запис (М05)
- **Определение:** приход/разход/салдо, свързан с обект/период.
- **Ключ:** `запис_id` · сметка, сума (центове), ДДС ставка, период, обект_id.

## Плащане / Вземане (М06)
- **Плащане:** входящ/изходящ паричен поток (`плащане_id`, сума центове, дата, метод кеш/банка).
- **Вземане:** дължима сума с падеж (`вземане_id`, договор_id/сделка_id, сума, падеж, статус).

## Проект / Дело / Задача (М07)
- **Проект/дело:** обхваща задачи по обект (`дело_id`).
- **Задача:** `задача_id` · име, начало, край, продължителност (дни), прогрес %, зависимости (Finish-to-Start).
- **Гант:** оцветена ТАБЛИЦА (не диаграма); такт Ден/Седмица/Месец/Година.

## Доставчик / Поръчка (М08)
- **Ключ:** `доставчик_id` · поръчки, материали, разходи по обект.

## Документ / Досие (М09)
- **Ключ:** `документ_id` · файл (Drive), тип, връзка към обект/договор/сделка.

## Контакт (М10)
- **Ключ:** `контакт_id` · лице/фирма; наемател/купувач/доставчик са контакти с роля.

## Събитие (М14) — атомът
- **Ключ:** `seq` (пореден) + `opId` (идемпотентен) + хеш (верига).
- **Определение:** единственият запис. Всяка промяна на горните е събитие тук.

## Потребител / Наемател-tenant / Роля (М13)
- **Самоличност:** имейл (без парола).
- **Изолация:** `наемател_id` (tenant) разделя данните между собственици.
- **Достъп:** реле Вижда / Скрито / Редактира.

## Диаграма на връзките (текст)

```
портфейл ─< имот ─< единица ─┬─ договор ─< вземане ─ плащане
                             └─ продажба ─ плащане
контакт ──(роля)── наемател / купувач / доставчик
дело ─< задача ─(зависимост FS)─ задача
всичко ── поражда ──> Събитие (Журнал)  ── проектира ──> Огледало
```
