# Наеми, договори и вземания (М02, М06)

## Business Context
Договорът свързва **единица** с **наемател** за срок. Той поражда **вземания** (месечен наем с
падеж), които се погасяват с **плащания**. Активността на договора зависи от периода.

## Ключови проекции

### договор
- **Ключ:** `договор_id` · единица_id, наемател_id, начало, край, наем_центове, индексация, депозит_центове.
- **Активен:** `начало ≤ :ден ≤ край` (или край празен).

### вземане
- **Ключ:** `вземане_id` · договор_id, период, дължимо_центове, падеж, статус.

### плащане
- **Ключ:** `плащане_id` · вземане_id, сума_центове, дата, метод (кеш/банка).

## Стандартни филтри
```
-- активни договори за период:
WHERE начало <= :край AND (край IS NULL OR край >= :начало)
-- изолация на наемодател (tenant):
  AND наемател_tenant = :текущ
```

## Примерни заявки
- **Месечни наеми:** `Σ наем_центове` по активни договори за месеца.
- **Просрочени вземания:** `Σ (дължимо − Σплащания)` за `падеж < днес И нето>0`.
- **Наематели с просрочие > 5 дни:** групирай по наемател_id, филтър `днес − падеж > 5`.

## Капани
- **Частични плащания** → винаги нето (дължимо минус сбора на плащанията по това вземане).
- **Индексация** мени наема във времето → чети наема към датата на периода, не първоначалния.
- Пари = центове; форматирай /100.
