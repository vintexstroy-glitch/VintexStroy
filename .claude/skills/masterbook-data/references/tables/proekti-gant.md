# Проекти, Гант, критичен път и ресурси (М07)

## Business Context
Дело обхваща задачи по обект. Задачите имат срок, прогрес и **зависимости** (Finish-to-Start).
Гантът е **оцветена ТАБЛИЦА** (клетки по такт), не истинска диаграма. Критичният път идва от CPM.

## Ключови проекции

### дело
- **Ключ:** `дело_id` · обект_id, име, статус.

### задача
- **Ключ:** `задача_id` · дело_id, име, начало, край, продължителност_дни, прогрес_%, зависимости[] (id-та).

### назначение (ресурс↔задача)
- **Ключ:** `назначение_id` · задача_id, ресурс_id, процент_капацитет.

### ресурс
- **Ключ:** `ресурс_id` · тип (човек/оборудване/материал), календар (работно време, почивни, отпуски).

## Изчисления
- **CPM:** Forward pass → ES/EF; Backward pass → LS/LF; **Slack = LF − EF**; `isCritical = Slack==0`.
- **Засечи цикли** (A→B→A) ПРЕДИ изчисление — иначе зацикляне.
- **Over-allocation:** за всеки ден `Σ процент_капацитет` на ресурса `> 100` → червено.

## Примерни заявки
- **Критични задачи:** филтър `isCritical = true`.
- **Забавени:** `край < днес И прогрес_% < 100`.
- **Претоварени ресурси (период):** ресурс с ден, в който сумарното назначение > 100%.

## Капани
- Гантът е таблица с оцветени клетки; такт Ден/Седмица/Месец/Година — не бъркай с диаграма.
- Зависимости без проверка за цикъл → безкраен цикъл в CPM.
- Календарът на ресурса (отпуски/почивни) мени наличния капацитет — не приемай 100% всеки ден.
