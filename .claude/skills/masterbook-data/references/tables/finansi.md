# Финанси · счетоводство, плащания, ДДС (М05, М06)

## Business Context
Счетоводните записи носят приход/разход/ДДС по обект и период. Парите текат през плащания.
ДДС се натрупва в **отделни акумулатори по държава/сектор** — не един общ.

## Ключови проекции

### запис (счетоводен)
- **Ключ:** `запис_id` · сметка, сума_стотинки, ддс_ставка, ддс_стотинки, посока (приход/разход), период, обект_id.

### плащане
- **Ключ:** `плащане_id` · сума_стотинки, дата, метод, свързан_id (вземане/сделка/разход).

## Стандартни филтри
```
-- приключен (замразен) период не се пипа:
WHERE период_статус <> 'замразен' OR :режим = 'само_четене'
```

## Примерни заявки
- **ДДС за внасяне (период):** `Σ ддс_стотинки(посока=приход) − Σ ддс_стотинки(посока=разход)`, **по акумулатор**.
- **Приход−разход по обект:** `Σ(приход) − Σ(разход)` групирано по `обект_id`.
- **Каса/банка салдо:** `Σ плащания(метод) входящи − изходящи`.

Sheets: `=SUMIFS(ддс_стотинки;посока;"приход";период;P) - SUMIFS(ддс_стотинки;посока;"разход";период;P)`

## Капани
- **Един общ ДДС акумулатор** = грешка; дръж по държава/сектор.
- **Float** → стотинкови разминавания. Само цели стотинки.
- **Замразен период** не се преизчислява (историческа истина).
