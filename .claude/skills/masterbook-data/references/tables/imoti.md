# Имоти · портфейл и заетост (М01)

## Business Context
Портфейлът е дърво: **място → сграда → етаж → единица**. Единицата (апартамент/офис/парцел) е
това, което се дава под наем ИЛИ се продава. Заетостта и наемният приход се смятат на ниво единица.

## Entity Clarification
- **имот** = сграда/място; **единица** = отделно даваема част (дете на имот).
- Заетост се брои по **единици**, не по имоти.

## Ключови „таблици" (проекции)

### имот
- **Ключ:** `имот_id`
- Полета: адрес, тип (жилищен/офис/парцел), площ, статус (актив/в строеж/продаден), портфейл_id.

### единица
- **Ключ:** `единица_id` (родител `имот_id`)
- Полета: етаж, площ, наемна_цена_центове, състояние (свободна/заета/продадена/в строеж).

## Стандартни филтри
```
-- само единици в наемния фонд:
WHERE състояние IN ('свободна','заета')   -- изключи 'в строеж','продадена'
```

## Примерни заявки
- **Заетост %:** `брой(състояние='заета') / брой(състояние IN('свободна','заета')) × 100`.
- **Свободни единици по сграда:** групирай по `имот_id`, филтър `състояние='свободна'`.
- **Портфейл по тип:** групирай единиците по `тип`, сумирай площ и наемна_цена.

Sheets: `=COUNTIFS(състояние;"заета") / COUNTIFS(състояние;"<>в строеж";състояние;"<>продадена")`
