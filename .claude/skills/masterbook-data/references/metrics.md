# Метрики · MasterBook

Всички парични метрики са в **цели стотинки**; форматирай към ЕВРО чрез `/100` — лев няма
(правило 3 · ADR-012). Агрегирай по
СЪБИТИЯ (сторно-модел), не по „последен ред".

---

## Наеми · месечни (приход)
- **Определение:** сумата на наемите по активни договори за месеца.
- **Формула:** `Σ наем_стотинки` за договори с `начало ≤ край_месец И (край IS NULL ИЛИ край ≥ начало_месец)`.
- **Източник:** Договор (М02).
- **Капан:** договор, започнал/спрял в средата на месеца — пропорционално, ако така е политиката.

## Вземания · просрочени
- **Определение:** неплатени вземания с падеж преди днес.
- **Формула:** `Σ (дължимо − платено)` за вземания с `падеж < днес И статус ≠ платено`.
- **Източник:** Вземане − Плащане (М06).
- **Капан:** частични плащания — вземи нето (дължимо минус сборa на плащанията по вземането).

## ДДС · за внасяне
- **Определение:** изходящ ДДС − входящ ДДС за периода.
- **Формула:** `Σ ДДС_изход − Σ ДДС_вход`, **по акумулатор (държава/сектор)** — не един общ.
- **Източник:** Счетоводен запис (М05).
- **Капан:** два и повече акумулатора; замразеното (приключен период) не помръдва.

## Заетост %
- **Определение:** дял заети единици.
- **Формула:** `заети_единици / общо_единици_под_наем × 100`.
- **Източник:** Единица (М01).
- **Капан:** изключи единиците „в строеж"/продадени от знаменателя.

## Приход / разход по обект
- **Формула:** `Σ приходи_стотинки − Σ разходи_стотинки` групирано по `обект_id`, за период.
- **Източник:** Счетоводен запис (М05), Доставчик/разход (М08).

## Критичен път (CPM) — за Гант
- **Определение:** най-дългата верига зависими задачи; Slack = LF − EF; `isCritical = (Slack == 0)`.
- **Метод:** Forward pass (ES/EF) → Backward pass (LS/LF) → Slack. **Засечи цикли** (A→B→A) преди изчисление.
- **Източник:** Задача + зависимости (М07).

## Натоварване на ресурс (over-allocation)
- **Определение:** ресурс, назначен над 100% от дневния капацитет в даден период.
- **Формула:** за всеки ден: `Σ % назначения на ресурса > 100` → маркирай червено.
- **Източник:** назначения задача↔ресурс + календар на ресурса (работно време, отпуски).

## Повторяемост / достоверност (за източника на думите — не бизнес, но живее в проекта)
- `ПОВТОРЕНО` = брой поява на едно изречение; `достоверност` = адрес разговор·съобщение / доклад.
