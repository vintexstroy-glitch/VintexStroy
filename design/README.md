# Дизайн · платното на MasterBook

Тук стои **източникът** на интерфейса. Сглобеният файл (`masterbook-interfeys.html`
в корена) се генерира и НЕ влиза в Git — 2,3 MB, от които почти всичко е редакторът.

```
Main.dc.html            Табло            ← входният артборд
Imoti.dc.html           Имоти
Naem.dc.html            Наем · детайл
Plashtaniya.dc.html     Плащания
Schetovodstvo.dc.html   Счетоводство · ДДС
Zhurnal.dc.html         Журналът
Gant.dc.html            Проекти и Гант
Telefon.dc.html         Телефон · приеми плащане (390×844)
SkitsaA.dc.html         Посока А · дневникът отпред
SkitsaB.dc.html         Посока Б · днешният списък
canvas.json             подредбата, страниците и бележките
build.py / ekrani.py    сглобяват артбордовете от общ стилов слой
```

## Пресглобяване

```bash
cd design && python3 ekrani.py
```

После платното се пресглобява със `seed-canvas.mjs` от design-скила и се качва
наново на същия адрес.

## Правила на визуалния език

- Топла хартия `#FBF8F3`, дълбоко мастило `#2A2521`, **един** акцент —
  теракота `#B25E38`; зелено `#2E7D5E` само за „затворено/платено".
- Literata за заглавия и числа, IBM Plex Sans за интерфейса, IBM Plex Mono за
  хешове и seq. И трите носят кирилица.
- Цифрите са **таблични** (`font-variant-numeric: tabular-nums`) — четат се в колона.
- Иконите са рисувани SVG на решетка 24, без емоджи.
- Състояние никога не се предава само с цвят — винаги има и дума.
- Подредбата е flex/grid с `gap`, не полета по елемент — оцелява при местене.

⚠️ Всички числа, имена и адреси в артбордовете са **измислени мостри**.
