# ACCRETION · Plate VII

**Stratigraphy of a Ledger** — A2, 420 × 594 mm.

| файл | какво |
| :---- | :---- |
| `ACCRETION.md` | философията на движението |
| `ACCRETION-plate-VII.pdf` | листът, векторен, за печат |
| `ACCRETION-plate-VII.png` | 200 dpi, 3308 × 4678 px |

## Как е направен

Нищо на листа не е нарисувано „на око". Полетата от марки са **байтовете
на истинска SHA-256 верига**: всеки пласт се смята от подписа на предишния, а
първите осемнайсет марки на всеки пласт са последните осемнайсет на горния —
`prevHash`, направен видим.

Разривът на пласт 18 е **истинско скъсване** на тази верига: там подписът не
произлиза от предшественика си. Затова полето е разместено, основата е
прекъсната, а наследяването спира — окото го усеща, преди да го е прочело.

Долу двете мерки не се събират. Липсва малко.

## Зависимости

```bash
pip install pycairo fonttools
```

Шрифтовете (Jura Light, IBM Plex Mono, IBM Plex Serif Italic) се четат от
`canvas-fonts` на скила `canvas-design` и се чертаят като контури, не се
типографират — затова изгледът не зависи от шрифтовете на машината.
