# VintexStroy · MasterBook

Приложение за управление на имоти, наеми, продажби, кредити, счетоводство,
плащания и проекти (Гант) — за един собственик с интензивен график.

**Местно-първо. Нула чужди зависимости в готовия пакет.** Журналът живее в
браузъра на собственика; няма сървър и няма мрежа.

## Пускане

```bash
npm install
npm run dev        # отваря екрана на http://localhost:5173

npm run typecheck  # типове
npm test           # тестовете
npm run proba      # проход през истински браузър
npm run merki      # бързината под договор
```

Данните живеят в IndexedDB на твоя браузър. Затвориш ли раздела, всичко си стои;
отвориш ли го другаде, е празно. Бутонът **Изнеси Журнала** сваля всичко като
`.json`, а **Архив за Ексел** — пет листа с готови филтри.

## Докъде е стигнато

Работещо приложение: имоти и наеми (с прекратяване, поправка и сторно), пари
(месечно начисляване, частични плащания), сметки (ДДС от общата цена, двете
страни, справка която **заключва** периода), източници (Excel · CSV · PDF се
ЧЕТАТ, не се качват), архив за Ексел с фини филтри, табло с вход без парола, и
офлайн джоб, който работи с прекъсната мрежа.

Непозната таблица не се гади: приложението **пита веднъж** коя колона какво е,
записва картата в Журнала, и вторият файл със същата глава минава сам. Ставката
на ДДС идва от реда, а сверката „фактури ↔ извлечения ↔ внесено" казва не само
колко се разминава, а КЪДЕ (ADR-009).

Пътищата са **бутони**, правени в Настройки: име, папка, действие, посока и кои
хедъри приемат. Един бутон гълта няколко файла наведнъж и ги сверява като една
партида; чужд файл се отказва на глас. Всяка числова колона се появява сама в
**Приход /+/** или **Разход /−/** според сбора си, а сверката влиза в Журнала —
и когато разликата е нула (ADR-010).

**Числата — преброени, не оценени — са в `docs/09` §4.** Тук нарочно не се
преписват: преписаното число рано или късно се разминава.

## Основни правила

Пълният списък е в **`CLAUDE.md`**. Петте, които държат всичко останало:

- **Истината живее само в Журнала** — само добавяне, хеш-верига, `opId`.
- Всичко останало е **производно** (Огледало) — изчислява се, не се съхранява.
- **Един вход за запис** — Вратата. Проверява право и валидност.
- **Поправка = ново събитие** (сторно). Никога презапис.
- **Парите са цели стотинки.** Никакъв float.

Всяка стъпка завършва със **сверка вход↔изход**; разликата се записва, дори
когато е нула.

## Сверка на веригата

`/refresh` минава цялата верига — от изворите в Драйва до последния файл тук —
и поправя разминатото на чисто, а приключеното мести в `docs/arhiv/`. Умението
е в `.claude/skills/refresh/`.
