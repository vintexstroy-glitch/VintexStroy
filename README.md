# VintexStroy · MasterBook

Приложение за управление на имоти, наеми, продажби, кредити, счетоводство,
плащания и проекти (Гант) — за един собственик с интензивен график.

## Пускане

```bash
npm install
npm run dev        # отваря екрана на http://localhost:5173
npm run typecheck
npm test
```

Данните живеят в IndexedDB на твоя браузър. Няма сървър и няма мрежа —
затова затвориш ли раздела, всичко си стои, а отвориш ли го другаде, е празно.
Бутонът **Изнеси Журнала** сваля всичко като `.json`.

## Докъде е стигнато

- **П1 · Ядрото** — готово: Журнал, Врата, хеш-верига, спирателен кран,
  дедупликация по `opId`, rev-предпазител, единичен писач на наемател.
- **Резен 1** — готов: имот → наем → вземане → плащане, от край до край,
  с Огледало (`fold`), сторно, което връща състоянието едно към едно,
  и сверка вход↔изход накрая.
- **Резен 2** — готов: работещ екран „Имоти", Журналът върху IndexedDB,
  проверка на веригата и изнасяне. Въведеното преживява презареждане.
- **П2 · Смятачът** — парите (цели стотинки, разпределяне, сторно, четене на
  сума от човек) са налице; ДДС акумулаторите предстоят.
- **Дизайн** — осем екрана в `design/` (виж `design/README.md`).
- **Миграцията на „Наеми КЕШ" е СПРЯНА** — сверката не затваря.
  Виж `docs/05-nahodki-naemi-kesh.md`.

65 теста минават, включително същите инварианти срещу IndexedDB.

## Основни правила

- **Истината живее само в Журнала** — дневник от събития, само добавяне, хеш-верига, `opId`.
- Всичко останало е **производно** (Огледало) — изчислява се, не се съхранява.
- **Един вход за запис** — Вратата. Проверява право и валидност.
- **Поправка = ново събитие** (сторно). Никога презапис.
- **Парите са цели стотинки.** Никакъв float.
- Всяка стъпка завършва със **сверка вход↔изход**; разликата се записва, дори когато е нула.
